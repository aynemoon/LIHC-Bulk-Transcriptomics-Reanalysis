## Historical attribution

The original report and script contents are unchanged. Research roles are recorded in [CONTRIBUTORS.md](../CONTRIBUTORS.md). Historical Git attribution is preserved separately in [original-commit-history.txt](original-commit-history.txt).

[original-history.bundle](original-history.bundle) is a complete Git archive of the original six-commit history through the pinned source revision. This archive preserves original authors, committers, dates, messages, trees and merge ancestry. The new repository's active history starts with its migration; the archive does not automatically populate GitHub's Contributors graph.

To inspect the archived history locally:

```sh
git clone original-history.bundle original-history
git -C original-history log --all --format=fuller
```

No changes to the original organization repository are needed to inspect or restore this archive. Its checksum is recorded in [archive-checksums.txt](archive-checksums.txt).
